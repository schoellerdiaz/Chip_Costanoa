World guide · Region

Harbor Blockade Perimeter

The Pacific approach. Open ocean outside the Golden Gate strait, patrolled by blockade fleets, and the last deep-water terminal the state still runs.

What is at stake here

Silicon. Every chip the state will get arrives through this fog or does not arrive. The Tàikōng transport Jade Current is running dark toward this terminal.

Locations

Eight Bridges Maritime Terminal

The state's last functioning container terminal, run by skeleton crews and automation nobody trusts. Gantry cranes frozen mid-lift over a quarantine quay in the fog.

Offshore Signal Relay Tower

A weather-beaten tower carrying Costanoa's only out-of-band signal path beneath the blockade's jamming: the last ear the state owns.
